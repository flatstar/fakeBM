## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client(DeliveryClient) → /api/wait/[id]/arrive | 클라가 도착/완주를 주장 — 신뢰 금지 |
| route id (sequential/guessable) → orders SELECT | IDOR 면 |
| client Date.now() countdown → 도착 판정 | 표시 전용, 서버가 deadline 재확인 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-3-04 | Tampering | 대기 마감 앞당김(클라 시계 조작/스킵 오용) | mitigate | arrive route가 `Date.now() >= waitDeadline.getTime()` 서버 재확인; 스킵=endured=false 명시 기록 (Pattern 2) |
