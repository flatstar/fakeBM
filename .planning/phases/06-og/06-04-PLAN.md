| client island → POST /api/shares | The entry button only triggers creation; the server (06-02) owns auth + snapshot authority |
| client → share targets | shareURL/navigator.share/clipboard operate on a same-origin /share/[id] URL only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10 | Tampering | client supplies stats via the entry POST | mitigate | The entry button sends an empty body; all authority lives in 06-02's server recompute — the client cannot inject stat values |
| T-06-11 | Information Disclosure | share text/URL leaking private data | mitigate | The shared URL is same-origin `/share/[id]` (opaque id); the share text is a fixed in-tone string with no PII (D-09) |
| T-06-12 | DoS | repeated empty share attempts | accept | Button disabled at resisted 0 + server 400 guard (06-02 T-06-06); rate-limiting deferred to v2 |
| T-06-07 | Tampering | untrusted host in the share URL | mitigate | url built from same-origin `${origin}/share/${id}` — never a client-supplied host |
</threat_model>
