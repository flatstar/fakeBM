<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public crawler/browser → /share/[id] (downstream) | The shares.id is the only key into a public un-authed row — it MUST be unguessable |
| session user → POST /api/shares (downstream) | Owner is taken from the session, never from a body field |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | shares.id sequential enumeration | mitigate | id is `text('id').primaryKey()` for an opaque `crypto.randomUUID()` (D-03) — NOT `generatedAlwaysAsIdentity()`; this plan locks the column type so a sequential int can never be introduced |
| T-06-02 | Information Disclosure | PII leak via snapshot columns | mitigate | shares stores only frozen stat scalars + byDay + topMenu — NO users.firstName/username column exists in the table (D-09); the leak is structurally impossible because the column is absent |
| T-06-SC | Tampering | build-time `fonttools` (PyPI) | accept | build-time only, not a shipped npm dependency; fonttools is a ~13yr-old canonical library (RESEARCH Package Legitimacy Audit) — no runtime bundle impact |
</threat_model>
