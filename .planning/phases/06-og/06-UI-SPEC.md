> Visual and interaction contract for the 공유 카드 & OG 이미지 phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Source of truth:** This phase has a **pixel-defined prototype** for the share card
> (`design-reference/screens-social.jsx` §`ShareCard` L173–223) and a **fully-locked design system**
> already ported in Phase 1 (`01-UI-SPEC.md` → `app/globals.css` `@theme`). This spec does NOT invent a new
> design — it **extracts and locks** the prototype's ShareCard, then specifies the **three distinct surfaces**
> the prototype's single overlay maps onto, each with a different rendering model.
>
> **Inherits wholesale from `01-UI-SPEC.md` (do not re-derive):** spacing scale, radii, shadows, full color

## THREE Surfaces (CRITICAL — different rendering models)

This phase has **one design** (`ShareCard` L173–223) rendered through **three surfaces** that do NOT share a
rendering engine. Every contract below is tagged with the surface(s) it applies to.

| # | Surface | Rendering model | Money rule | Reachable when |
|---|---------|-----------------|-----------|----------------|
| **S1** | **OG image** `app/share/[id]/opengraph-image.tsx` | **Satori-rendered PNG** (1200×630), **flexbox-only**, **embedded subset fonts**, **NOT DOM/Tailwind** | ₩/digits via **embedded-font** `tabular-nums` text (NOT `<Won>`) | crawler preview / `og:image` (SHARE-02/03) |
| **S2** | **In-app share sheet** (`_components/ShareSheet`, client island over /stats·/my) | **Real DOM/Tailwind**, `var(--color-*)` tokens, locked design system | `<Won>` / `<Num>` (DOM HARD RULE) | authed user inside Telegram (SHARE-01/04) |
| **S3** | **Public `/share/[id]` page** `app/share/[id]/page.tsx` | **SSR DOM**, no Telegram shell, opens in any browser | `<Won>` / `<Num>` (DOM HARD RULE) | anyone, no auth (SHARE-03) |

**Money HARD RULE (inherited, surface-split):**
- **S2/S3 (DOM):** every ₩/kcal/count/stat renders through `<Won>`/`<Num>` (`lib/format.ts`), Pretendard `tabular-nums`. BMHanna ₩ renders as a narrow `~` (Phase-1 Pitfall 7) — never route ₩ through a BM font.
- **S1 (Satori OG):** `<Won>`/`<Num>` React components **cannot** be used inside `ImageResponse`. Render the ₩ amount as raw `fmtWon(...)` text in a span with `fontFamily:'Pretendard'` (the subset that includes ₩ U+20A9 + digits) + `fontVariantNumeric:'tabular-nums'`. ₩ goes in the **Pretendard** subset, NEVER the BM subset (RESEARCH Pitfall 4).

## Typography

The DOM (S2/S3) surfaces render a **4-step closed type scale `{44, 18, 14, 11}`px**. This is a
**Phase-1-inherited closed token set** — the prototype/Phase-1 type scale was already checker-approved, so this
reduced 4-step set is **locked, not invented**: the prototype's near-duplicate sizes are merged onto the nearest
locked step (17/16→18, 13→14, 11.5→11) to keep a clear hierarchical step at every level. **No new DOM sizes are
introduced.** **S1 (OG) scales each of the same 4 steps ~2× to fill 1200×630** → `{88, 36, 28, 22}`px, reading
from the embedded subset fonts; these are derivations of the locked scale, not new design tokens.

**The 4-step DOM scale (S2/S3) → S1 OG derivation:**

| Step | S2/S3 size | S1 OG (≈2×) | Roles at this step |
|------|-----------|-------------|--------------------|
| **1 (hero)** | **44px** | **88px** | Hero ₩ amount |
| **2 (lead/value)** | **18px** | **36px** | Stat value · Overlay title (S2) · Wordmark |
| **3 (body)** | **14px** | **28px** | kcal line · Card lead line |
| **4 (caption)** | **11px** | **22px** | Month-report label · Stat caption · Footer credit · Share-target label (S2) |

| Role | S2/S3 size | S1 OG size (≈2×) | Weight | Line Height | Font | Used for |
|------|-----------|------------------|--------|-------------|------|----------|
| Hero amount (₩, chunky/Pretendard) | 44px | 88px | 800 | 1.05 | **`<Won>`→Pretendard** (S2/S3) · **'Pretendard' subset** (S1), tabular-nums, color coral | "이번 달 아낀 돈" figure (prototype L191) — the one oversized hero number |
| Stat value (chunky) | 18px | 36px | 800 | 1.0 | BMDohyeon (`--font-chunky`) · 'BMDisplay' (S1) — **numeric portion Pretendard tabular-nums** | "🔥 {streak}일 / ✋ {resisted}번 / 🏆 {topMenu}" (prototype L203), `whiteSpace:nowrap` |
| Overlay title (S2 only) | 18px | — | 800 | 1.2 | BMHanna | "공유 카드" sheet header (prototype L179; 17→18 merged to step 2) |
| Wordmark | 18px | 36px | 800 | 1.2 | BMHanna (`--font-display`) · 'BMDisplay' (S1) | "배달의 만족" (prototype L187; 16→18 merged to step 2) |
| kcal line | 14px | 28px | 700 | 1.2 | BMHanna (`--font-display`) · 'BMDisplay' (S1) — **but `{kcal}` digits + "kcal" route Pretendard** (HARD RULE) | "아끼고 {kcal}kcal 덜 먹었어요" (prototype L192) |
| Card lead line | 14px | 28px | 600 | 1.4 | Pretendard, `rgba(255,255,255,.7)` | "이번 달, 시켜놓고 참아서" (prototype L190; 13→14 merged to step 3) |
| Month-report label | 11px | 22px | 600 | 1.2 | Pretendard, `rgba(255,255,255,.6)` | "{month} 리포트" (prototype L188) |
| Stat caption | 11px | 22px | 600 | 1.3 | Pretendard, `rgba(255,255,255,.55)` | "연속 / 참음 / 최다 적" (prototype L204), `whiteSpace:nowrap` |
| Footer credit | 11px | 22px | 600 | 1.3 | Pretendard, `rgba(255,255,255,.45)`, centered | "＠배달의_만족 · 참아서 만든 기록" (prototype L208) |
| Share-target label (S2 only) | 11px | — | 700 | 1.0 | Pretendard | 저장/링크/인스타/카톡 (prototype L216; 11.5→11 merged to step 4) |

Notes:
- **Two primary weights** (Phase-1 contract): regular/medium **500–600** for secondary text, bold **700–800** for emphasis/headings/numbers. BM fonts read as a single heavy weight.
- **HARD RULE (surface-split, see THREE Surfaces):** S2/S3 numbers via `<Won>`/`<Num>`; S1 numbers via the embedded **'Pretendard'** subset span with `fontVariantNumeric:'tabular-nums'`. ₩ (U+20A9) lives **only** in the Pretendard subset.
- **S1 mixed-font lines:** "아끼고 {kcal}kcal 덜 먹었어요" and the stat values mix Korean (BMDisplay subset) + digits/`kcal` (Pretendard subset). In Satori, wrap the numeric run in a nested `<span style={{fontFamily:'Pretendard'}}>` so the digit + ₩ glyphs come from the correct subset.
- **CLOSED 4-STEP SCALE:** the DOM scale is exactly `{44, 18, 14, 11}`px — a Phase-1-inherited, already-approved closed token set, locked here. Adding a new DOM size requires updating this contract first. S1 OG sizes (`{88, 36, 28, 22}`px) are the same 4 steps derived ≈2× for the 1200×630 canvas, not new design tokens.

## Share Actions (SHARE-04 — S2 + S3)

The prototype's 4 targets (💾 저장 / 🔗 링크 / 📷 인스타 / 💬 카톡, L213) map to **real actions** (D-11). The 4-button
visual row is preserved; behavior is wired per RESEARCH §Share actions island + Pitfall 7.

| Target | Glyph | Action | Availability fallback |
|--------|-------|--------|----------------------|
| **저장** | 💾 | Download the OG PNG: `<a href={ogUrl ?? '/share/${id}/opengraph-image'} download>` | Always available (S2 + S3). |
| **링크** | 🔗 | Copy public URL: `navigator.clipboard.writeText('${origin}/share/${id}')` → toast "링크를 복사했어요!" | Always available; toast confirms. |
| **인스타 / 외부공유** | 📷 | `navigator.share({ url, text })` (Web Share API → OS sheet, covers 인스타/etc) | If `navigator.share` absent → clipboard copy + toast. |
| **카톡 / 텔레그램** | 💬 | **Telegram-native first:** `shareURL(url, text)` (`@telegram-apps/sdk`, `.isAvailable()`-wrapped) | If not in Telegram (e.g. S3 in a desktop browser) → `navigator.share` → clipboard. |

**Action priority chain (the share button logic):** `shareURL.isAvailable()` → else `navigator.share` → else `navigator.clipboard.writeText`. The 저장 download is independent and always shown. Share `text` = "나 이번 달 이만큼 참았어 👀 #배달의만족" (in-tone, 자랑 framing — never 굶기).

**Toast (inherited Phase-1 toast primitive):** every copy/share success shows a brief in-tone toast (e.g. "링크를 복사했어요!", "저장했어요!"). Avoid entrance-fade-stuck-at-opacity:0 (Phase-1 animation note) — toasts must guarantee a final visible state.

## Empty / Disabled State (0-인증 — CONTEXT D discretion, RESEARCH Pitfall 6)

A user with **0 인증** (`resisted === 0`) has no meaningful card. **Belt-and-braces guard (recommended in RESEARCH):**

| Layer | Behavior |
|-------|----------|
| **Entry CTA (UI)** | "공유 카드 만들기" `TgMainButton` is **disabled** when `resisted === 0` (the /stats page already computes `isEmpty`). Disabled style = Phase-1 `TgMainButton` disabled (`bg:#E3D8CE`, no shadow, no press). |
| **Helper copy** | Below/near the disabled CTA: "먼저 인증하세요 — 참은 기록이 있어야 카드를 만들 수 있어요" (in-tone, 절약/선택; NEVER 굶기). |
| **Server guard** | `POST /api/shares` returns **400 `{ error: 'empty' }`** on an empty snapshot (defense in depth — the button should already be disabled). |
| **Client handling of 400** | Show toast "먼저 인증하세요 🙏" — do not crash, do not navigate. |

There is **no empty state for `/share/[id]` itself** — a share only exists if it was created from a non-empty snapshot, and an unknown id → `notFound()` (404).

## Accessibility (inherited Phase-1 rule — Dim 2)

- **Icon-only buttons carry `aria-label`** (Phase-1 TgHeader rule): overlay close `x` → "닫기"; each share-target button → its label ("저장"/"링크"/"인스타"/"카톡") even though an emoji + text label is present (the emoji alone is not an accessible name).
- **S3 public page** is a standalone web document: set a meaningful `<title>` (metadata above) and ensure the card text is real DOM text (not baked into an image) so it is selectable/readable by screen readers — the S1 OG PNG is the crawler preview, but S3's human page renders text as DOM.
- Color contrast: white / coral text on the dark `#2a1d14→#52331f` gradient passes for the large display sizes used; the low-opacity captions (`.45–.55`) are decorative credit/labels at ≥11px.
