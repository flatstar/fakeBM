<objective>
Build `POST /api/shares` — the server-authority snapshot creator. It mirrors `POST /api/posts`: `requireSession()` gives the owner tgId, the entire snapshot is recomputed from `lib/stats` (the client body carries NO stat values), an opaque `crypto.randomUUID()` is the PK, and an empty (0-인증) snapshot is rejected 400 before any insert.

Purpose: SHARE-01 — the user generates a share card from their own real, server-computed stats. Server-authority prevents a client from forging savings/kcal (T-06 Tampering); the empty guard (Pitfall 6) prevents degenerate all-zero cards.
Output: `app/api/shares/route.ts` returning `{ id }`, fully unit-tested.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session user → POST /api/shares | Owner identity (tgId) crosses from the verified session — never from the request body |
| client body → snapshot | The body is untrusted; all stat values are recomputed server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Tampering | client-forged stats in POST body | mitigate | Snapshot is recomputed from `lib/stats` server-side; body carries no stat values (mirrors POST /api/posts); test (c) asserts forged body fields are ignored |
| T-06-04 | Elevation / IDOR | creating a share for another user | mitigate | tgId comes only from `requireSession()` — never a body/param field; no user-supplied owner path exists |
| T-06-05 | Information Disclosure | unauth share creation | mitigate | `if (!tgId) return 401` before any work; test (a) asserts no insert on no-session |
| T-06-06 | DoS | unbounded share creation (spam) | accept | Empty-stats guard (Pitfall 6) blocks degenerate spam; per-rate limiting deferred to v2 (RESEARCH Security Domain — v1 trust) |
</threat_model>
