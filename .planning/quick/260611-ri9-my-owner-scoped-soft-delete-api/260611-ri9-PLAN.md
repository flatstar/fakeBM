    6. `db.update(posts).set({deletedAt: sql`now()`}).where(and(eq(posts.id, postId), eq(posts.tgId, tgId), isNull(posts.deletedAt)))` — owner-scope를 UPDATE WHERE에도 중복 포함 (belt-and-braces) + isNull 가드로 트랜잭션 없이 멱등 (neon-http는 db.transaction 없음 — 단일행 UPDATE라 불필요).
