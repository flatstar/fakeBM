문서 필수 섹션:
1. **오브젝트 인벤토리** — 예상 오브젝트: User(users), Order(orders — jsonb items 스냅샷 + 대기/도착 컬럼 포함), Post/인증(posts — 듀얼 사진·diet·caption·streak), Like(likes 복합 PK), Report(reports), Share/공유카드(shares — frozen snapshot, opaque text PK), Restaurant/Menu(lib/catalog.ts 시드, DB 비영속), Cart(localStorage 클라이언트 오브젝트), Stats(파생 집계 — lib/stats.ts), Handle(파생 — lib/handle.ts FNV-1a). 코드 확인 후 가감.
2. **오브젝트별 상세** — 각 오브젝트마다: core content(attributes — 실제 컬럼/필드명 원형), metadata(createdAt, hiddenAt/deletedAt, arrivedAt 등), nested objects(Order.items 등), 상태/라이프사이클(예: Order: 생성→대기→도착(endured 여부); Post: visible→hidden→deleted).
3. **관계 매트릭스** — 오브젝트 × 오브젝트 테이블 (1:N, 1:1 UNIQUE — posts.order_id, N:M — likes 등). FK·UNIQUE 제약을 schema.ts에서 인용.
4. **오브젝트별 CTA 목록** — 각 오브젝트에 대해 사용자가 실제로 할 수 있는 액션과 그것이 구현된 라우트/API 매핑 (예: Order — 생성: `/cart`→`POST /api/orders`, 조회: `/order/[id]`, 대기 시작/도착: `/wait/[id]`→`/api/wait` 또는 `/api/orders` 하위 — 실제 라우트 확인). Like 토글 `POST /api/posts/[id]/like`, Report `POST /api/posts/[id]/report`, Share 생성 `POST /api/shares` 등.
5. **오브젝트 → 화면 매핑 테이블** — 라우트별로 표시되는 주 오브젝트/보조 오브젝트 ( (boot), home, store/[id], cart, order/[id], wait/[id], post/[id], feed, stats, my, share/[id], admin).
6. **OOUX 관찰/개선 노트** — 구조적 특이점 (예: Cart만 비영속 클라이언트 오브젝트, Share는 live 참조가 아닌 동결 스냅샷, 익명 Handle은 저장 없이 결정론적 파생 등) 5개 내외.
